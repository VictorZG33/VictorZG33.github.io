# wentaoz.com

Personal homepage of Wentao Zhang, served by GitHub Pages at https://wentaoz.com.

The whole site is one file, `index.html` (no build step). Edit it and push to `main`; GitHub Pages redeploys in about a minute.

- `CNAME` tells GitHub Pages which custom domain to serve (don't delete it).
- `.nojekyll` turns off Jekyll processing so the file is served as-is.
